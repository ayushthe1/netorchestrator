# NetOrchestrator Documentation

This folder contains all documentation, guides, status reports, and planning documents for the NetOrchestrator project.

## 📚 Documentation Structure

### 📊 Status Reports (`status/`)
Current status reports and implementation summaries:
- `CURRENT_STATUS.md` - Current system status and what's working
- `STATUS_REPORT.md` - Detailed status report with endpoints and issues
- `IMPLEMENTATION_COMPLETE.md` - Event-driven architecture implementation summary

### 📖 Guides (`guides/`)
How-to guides and quick start documentation:
- `COMPLETE_TESTING_GUIDE.md` - Comprehensive testing guide
- `POSTMAN_TESTING_GUIDE.md` - Postman API testing guide
- `DOCKER_COMMANDS.md` - Docker commands and operations
- `QUICK_START.txt` - Quick start instructions
- `README_QUICK_START.md` - Quick start README
- `STARTUP.md` - Startup instructions

### 🎯 Planning (`planning/`)
Planning documents and roadmaps:
- `HACKATHON_5DAY_PLAN.md` - 5-day hackathon implementation plan
- `ROADMAP.md` - Project roadmap

### 📮 Postman Collections (`postman/`)
Postman collections and testing documentation:
- `NetOrchestrator_Complete_Collection.json` - Complete Postman collection
- `NetOrchestrator_Postman_Collection.json` - Postman collection
- `POSTMAN_ENDPOINT_TESTING_TABLE.md` - Endpoint testing table

### 🧪 Testing (`testing/`)
Testing documentation and endpoint information:
- `ENDPOINT_COUNT.md` - Endpoint count summary
- `API_ENDPOINTS.md` - Complete API endpoints documentation

### 🏗️ Architecture & Overview
Architecture and platform documentation:
- `ARCHITECTURE.md` - System architecture documentation
- `ENTERPRISE_PLATFORM.md` - Enterprise platform features
- `PLATFORM_OVERVIEW.md` - Platform overview
- `PODMAN_MIGRATION.md` - Podman migration guide
- `MVP_README.md` - MVP implementation README
- `BEEKEEPER_CONNECTION.md` - Beekeeper connection documentation
- `API.md` - API documentation
- `automation-system.md` - Automation system documentation

### 📄 Swagger Documentation (`swagger/`)
Auto-generated API documentation:
- `swagger.json` - Swagger JSON specification
- `swagger.yaml` - Swagger YAML specification
- `docs.go` - Go documentation
